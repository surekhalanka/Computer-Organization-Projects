📋 Project Overview

In this project, you'll design and verify a 4-bit Arithmetic Logic Unit (ALU) from gate-level components. You'll construct full adders, multiplexers, and control logic to create a functional ALU that performs arithmetic and logic operations on 4-bit numbers. This builds deeper understanding of how processors implement computation at the hardware level.

🎯 Real-World Scenario

ChipDesign Corp: Building an Ultra-Low-Power 4-Bit Microprocessor

Background: ChipDesign Corp manufactures IoT microcontrollers for smart home devices. A cost-effective 4-bit ALU can reduce die size by 40% and power consumption by 60% compared to 8-bit designs. Your team must verify the correctness and efficiency of a 4-bit ALU design across 16 different test cases before manufacturing 10 million units.

Design Constraints:

  • Bit Width: 4-bit operands (0-15 range)
  • Operations: ADD, SUB, AND, OR, XOR, NOT (6 core operations)
  • Gate Limit: < 200 logic gates (cost constraint)
  • Propagation Delay: < 5ns per operation (speed requirement)
  • Power Dissipation: < 50mW @ 1GHz (thermal constraint)
  • Testability: All 16 test vectors must pass without fault

Core Components:

Component Purpose Gate Count Propagation Delay
Full Adder (1-bit) Add two bits with carry 9 gates 1.5ns
Full Adder (4-bit) Add 4-bit numbers 36 gates 6ns (ripple carry)
2-to-1 Multiplexer Select between inputs 3 gates 0.5ns
4-to-1 Multiplexer Select ALU operation 12 gates 1.0ns
AND Gate (4-bit) Bitwise AND operation 4 gates 0.2ns
OR Gate (4-bit) Bitwise OR operation 4 gates 0.2ns
XOR Gate (4-bit) Bitwise XOR operation 8 gates 0.3ns
NOT Gate (4-bit) Bitwise NOT operation 4 gates 0.1ns

OpCode Encoding (3-bit select):

OpCode[2:0] = Operation
000 = ADD (A + B)
001 = SUB (A - B)
010 = AND (A & B)
011 = OR (A | B)
100 = XOR (A ^ B)
101 = NOT (¬A)
110 = SHL (A << 1)
111 = SHR (A >> 1)

Critical Path Analysis:

  • ADD Operation: 4-bit ripple carry adder = 6ns (critical path)
  • SUB Operation: 4-bit adder + NOT gate = 6.1ns
  • Logic Operations: Parallel gates = < 1ns
  • Multiplexer Delay: +1ns to select final output
  • Total ALU Delay: 6ns + 1ns = 7ns (violates 5ns target)

Optimization Opportunities:

  • Carry Lookahead Adder (CLA): Replace ripple carry → 3ns, but uses +20 gates
  • Pipelined Design: Split into 2-stage pipeline → 4ns per stage
  • Gate Sharing: Reuse logic between operations (NOT for SUB precompute)
  • Clock Gating: Disable unused ALU units to reduce power
