📋 SCENARIO: Image Brightness Adjustment

Context: A real-time image processing system adjusts brightness of a 256×256 pixel image.

Task: Process pixels by loading from memory, performing arithmetic operations (multiply for brightness), and storing results.

Complexity:

  • Read pixel data from memory (addresses 0x1000-0x10FF)
  • Load brightness factor from register
  • Execute multiplication instructions for each pixel
  • Store adjusted values back to output memory (0x2000-0x20FF)
  • Track instruction timing and cache performance
